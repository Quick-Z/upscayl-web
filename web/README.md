# enhance Web 工作台

这是一个不依赖构建工具的静态网页，用于调用项目中的 enhance HTTP API。

## 启动

在项目根目录执行一次：

```bash
npm start
```

也可以通过环境变量修改网页服务监听地址和端口：

```bash
API_HOST=0.0.0.0 API_PORT=3000 WEB_HOST=0.0.0.0 WEB_PORT=8080 npm start
```

浏览器访问：

```text
http://127.0.0.1:5173
```

页面使用内置 API 地址进行请求，API 地址不在界面中暴露或配置。

## 使用

1. 拖入或选择 PNG、JPG/JPEG、WEBP 图片，可一次加入最多 10 张。
2. 选择模型、放大倍数和输出格式。
3. 点击“升图”，图片会按队列顺序处理，避免 API 并发冲突。
4. 处理完成后在右侧画布同时查看原图与结果，并下载当前图片。

每张图片会以原始二进制请求体提交到 `POST /api/jobs`，服务端立即返回任务 ID，并由页面通过 SSE 和轮询查询进度。页面不会将图片上传到第三方服务。
